# Flip 7 Punkteblock

Eine kleine Web-App zum Festhalten eurer Flip-7-Punkte. Fürs iPhone gestaltet, zu zweit oder mit bis zu 18 Personen spielbar.

Wählt eure Namen und ein Punktziel, dann kann es losgehen. Nach jeder Runde tragt ihr die Punkte direkt ein oder wählt eure Karten aus und lasst die App rechnen. Gesamtsummen und Rundenverlauf bleiben im Blick, Eingaben lassen sich nachträglich korrigieren.

Namen und die laufende Partie werden auf eurem Gerät gespeichert. Über Safari könnt ihr die App zum Home-Bildschirm hinzufügen und nach dem ersten Online-Aufruf auch offline verwenden.

## Lokal starten

Mit Node.js 24:

```sh
npm ci
npm run dev
```

Im Browser unter `http://localhost:3000` öffnen. Auf dem iPhone im selben WLAN verwendet ihr die IP-Adresse des Macs mit Port `3000`.
